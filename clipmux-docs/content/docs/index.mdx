ClipMux is a developer-first VOD platform for ingesting files, preparing adaptive streams, and delivering playback globally without the pricing overhead of traditional enterprise video platforms.

This docs site is the working home for the platform docs. For now it covers the broad product shape and key concepts. We will tighten the details later as the APIs and workflows settle.

## Why ClipMux

- Lower the cost of operating a video platform without losing the core building blocks developers expect.
- Provide one place for upload, transcoding, packaging, playback access, and delivery controls.
- Stay API-first so product teams can build fully custom video experiences instead of adapting to a rigid dashboard.

## What You Can Expect

- Asset ingestion for VOD workflows
- Transcoding and playback preparation
- Signed delivery patterns for controlled access
- Developer-friendly API and SDK surfaces
- Documentation that will expand alongside the platform

## Current State

This documentation is intentionally broad for now. It is meant to establish the platform story and give you a stable starting point while we fill in endpoint-level detail, examples, and operational guidance.
