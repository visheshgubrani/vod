OpenVOD is an open-source, self-hosted VOD platform (Apache-2.0). Paste your
Cloudflare R2 credentials and Modal API key and get Mux-style HLS/DASH
ingestion: multipart uploads, GPU transcoding with adaptive-bitrate ladders,
signed playback URLs, AI subtitles & chapters, tenant webhooks and analytics.

> The full Quickstart, BYOK walkthrough, environment reference and API details
> live in the repository README and the `docs/` folder (delivery contract,
> deploy). Content here is a navigable subset of that.

## Why OpenVOD

- Bring-your-own-keys: no vendor lock-in for storage, compute or database.
- Mux-style DX: upload tokens, typed transcode callbacks, signed playback.
- Truly open: Apache-2.0, no metered SaaS behind the scenes.
