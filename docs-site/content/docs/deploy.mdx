---
title: Deployment
description: Wrangler default vs Docker API/web. Delivery stays on Cloudflare Workers.
---

OpenVOD is hybrid: the **API and dashboard** run on Cloudflare Workers (default)
or Docker/Node. The **delivery worker is Cloudflare-only**. Compose does not
serve signed HLS/DASH.

The canonical walkthrough is [`docs/deploy.md`](https://github.com/visheshgubrani/vod/blob/main/docs/deploy.md)
in the repository. Key facts:

- **API**: Cloudflare Workers (`DB_DRIVER=neon-http`) or Node container
  (`DB_DRIVER=pg`, `@hono/node-server`) — same Hono app.
- **Delivery**: Cloudflare Worker (R2 binding, JWT verification, manifest
  rewriting, bandwidth metering). Set `DEFAULT_POLICY=signed` to fail closed
  on objects missing policy metadata. Add your custom domain after
  `wrangler deploy` (configs ship with commented examples, not live hostnames).
- **Storage**: Cloudflare R2. Generic S3/MinIO is not implemented yet.
- **Transcoding**: Modal GPU only.
- **Web dashboard**: Next.js standalone (Vercel or Docker). `NEXT_PUBLIC_*`
  is baked at image build time.
- **Zero-touch boot**: the API container runs `src/node/migrate.ts` before
  serving; migrations are advisory-locked and idempotent across restarts.
- **Health**: `GET /health` (liveness), `GET /health/config` (BYOK capability
  flags including an advisory `delivery` check, no secrets), delivery
  `GET /health`, Modal `GET /healthz`.
- **Recovery**: heartbeat-aware job sweeper; Workers cron (`SWEEP_ENABLED` +
  `triggers.crons`) or `POST /api/internal/sweep` with `INTERNAL_SWEEP_SECRET`.
