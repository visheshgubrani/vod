The full first-run guide (what to create in Cloudflare, which keys to copy,
R2 CORS, Modal secrets) is the repository
[README](https://github.com/visheshgubrani/vod#prerequisites).

You need **before clone**:

- Cloudflare account → two R2 buckets (raw + transcoded) + R2 API token
- Wrangler login (delivery worker is always Cloudflare)
- Postgres (Neon) **or** Docker Compose’s Postgres
- Modal account (`pip install modal && modal setup`)

Then `pnpm install && ./scripts/bootstrap.sh`. The installer logs into
Cloudflare and Modal, creates the R2 buckets, deploys workers + Modal, and
asks you to paste the R2 S3 token (and a Neon URI unless you pick Docker).

## Path A — Cloudflare Workers + Vercel

1. `scripts/setup.sh` (choose **workers** → `DB_DRIVER=neon-http`).
2. `pnpm db:push`.
3. `wrangler deploy` in `server/` and `delivery/`. Set `DELIVERY_URL`.
4. Modal secrets `r2-creds` / `groq-creds`, then `modal deploy main.py`.
   Set `ALLOWED_CALLBACK_HOSTS` and `ALLOWED_SOURCE_BUCKETS`.
5. Import `web/` into Vercel (`NEXT_PUBLIC_*`) or run the Docker web image.

## Path B — Docker Compose (API + web + Postgres)

```bash
docker compose up -d
```

Postgres + API + web boot together; the API migrates before listen.
Dashboard: `http://localhost:3000`. API: `http://localhost:8787`.

**Playback still needs the Cloudflare delivery worker** in front of R2.
Compose does not include it.

## Verify

- `curl <api>/health` → `ok`
- `curl <api>/health/config` → JSON capability checks
- Open `<frontend>/setup` for the BYOK status page.
